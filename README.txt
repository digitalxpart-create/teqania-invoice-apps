AL TEQANIA Invoice & Quotation Android App — source project

Included:
- Android WebView app project (open this folder in Android Studio)
- Invoice and quotation modes
- Add/remove service items; subtotal, discount, VAT and total calculations
- Saved documents and remembered service descriptions on the same device
- Print / Save as PDF via Android print dialog
- WhatsApp sharing
- JSON backup and restore

Build an APK:
1. Install Android Studio on a computer.
2. Open this TeqaniaInvoice folder in Android Studio.
3. Let Gradle sync; install Android SDK Platform 35 if prompted.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. The debug APK is usually at app/build/outputs/apk/debug/app-debug.apk.

Important:
- This is the Android Studio source project, not a precompiled APK.
- Saved data is stored locally on the phone/browser app data. Use Backup Data regularly.
- The app currently uses the company's updated address and contact details in the template.
